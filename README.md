# Smart Campus Booking System

## 📌 Module: Resource Booking

This project is part of the Smart Campus Booking System developed for the PAF module.  
This repository contains my implementation of the **Resource Booking** functionality.

---

## 🚀 Features (Resource Booking)

- 📅 Book campus resources (rooms, labs, etc.)
- 📝 Submit booking requests
- 👤 User authentication (Login/Register)
- 📋 View user bookings
- ❌ Cancel bookings
- 🛠️ Admin can manage all bookings

---

## 🏗️ Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Spring Boot (Java)
- REST API

### Database
- MySQL / H2 (depending on setup)
